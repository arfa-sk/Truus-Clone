# Truus Clone - Portfolio Project

This is a high-fidelity clone of the Awwward-winning Truus.co website, rebuilt using **Next.js 15, React 19, and GSAP**. It features complex scroll animations, custom cursor tracking, elastic physics, and a responsive modern design.

## Tech Stack
- Next.js
- React
- Vanilla CSS
- GSAP & Lenis

## Setup
1. `npm install`
2. `npm run dev`
